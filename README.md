A simple **Rock-Paper-Scissors game** built with Python.  
The player competes against the computer, which randomly chooses Rock, Paper, or Scissors.

##  About the Project

This is a beginner-friendly Python console game created to practice:

- Python basics
- `while` loops
- `if / elif / else`
- `try / except`
- Lists
- User input
- The `random` module
- Conditional logic

##  How to Play

When the game starts, choose one of these options:

```text
1 - Rock
2 - Paper
3 - Scissors
```

The computer then randomly selects its choice.

###  Winning Rules

| Rock🪨   | Pape📄     | Paper Wins|
| Rock🪨   | Scissors✂️ | Rock wins|
| Paper 📄 | Rock 🪨    | Paper wins |
| Paper 📄 | Scissors✂️ | Scissors wins |
| Scissors✂️ | Rock🪨  | Rock wins |
| Scissors✂️ | Paper📄 | Scissors wins |
| Same choice| Same choice | Tie |
